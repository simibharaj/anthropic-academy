# Anthropic Academy

My hands-on coursework from Anthropic's free [Claude Academy](https://academy.claude.com/) courses: my own notes and small educational examples. This repo does not contain Anthropic's course content, which belongs to Anthropic.

The code here is educational, not production-ready. It uses fake data only, and any API key is read from an environment variable, never stored in the repo.
